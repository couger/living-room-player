# 家庭局域网安全

## 连接与数据

| 通道 | 实现与边界 |
| --- | --- |
| 原生控制，TCP 8766 | TLS、设备证书 SHA-256 固定、独立随机凭据和同子网来源检查；同网段不等于可信 |
| 发现，UDP 8767 | 返回设备名称、型号、端口和指纹，不返回控制凭据；可在受控端关闭 |
| 配对 | 受控端临时开放三分钟，六位数字核对，本机批准后用请求方 RSA 公钥加密返回独立授权 |
| PC WEB，默认 TCP 8760 | 仅监听 127.0.0.1；浏览器到本机为 HTTP，本机到设备为固定证书的 TLS；请求令牌、Host 和管理 POST 来源检查 |
| 系统 ADB | 独立于应用连接；日常可关闭 USB／无线调试 |

凭据、密钥与配置保存在受保护的本机目录。PC 工具不把控制令牌或私钥交给浏览器；保存设备 ID 不等于保存控制凭据。不要公开连接码、设备档案或签名文件。

## 配置自主权

充电、待机策略、音乐 APP、按键绑定、服务管理和配对批准仅允许受控端本机管理接口。控制端保留日常屏幕操作和状态查看。该分工不构成屏幕级沙箱：已授权的完整屏幕操作仍可能进入设备设置。

没有细分只读权限或独立安全审计。ROOT 助手和屏幕控制权限较高，截图可能包含账号、通知或其他私人信息。工具不采集麦克风，不调用音乐账号私有 API。

## 使用边界

只在可信家庭网络使用，不将应用控制、发现或 ADB 端口映射到公网。旧设备如仍有 HTTP Basic 的设备内 WEB 服务，该通道没有 TLS，应按需关闭；现代 PC 工具无需开启它。

“关闭画面”只停止画面传输；“断开连接”停止当前控制页请求；“忘记设备”删除本机档案；“撤销授权”阻止该独立凭据再次访问；“停止服务”停止受控功能并恢复本工具管理的充电设置。已经执行的操作不能撤回。

参考 [配对与授权](security-controls.md) 与 [本机配置职责](power-ownership.md)。
