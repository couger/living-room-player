# PC WEB 工具

工具在 PC 本机运行，不要求受控端提供设备内 HTTP 服务。需要 Python 与 cryptography：

```powershell
python -m pip install -r tools/web-requirements.txt
python tools/web-debug-toolkit.py --port 8760
```

也可运行根目录的“启动WEB调试工具.cmd”，再打开 http://127.0.0.1:8760/。

## Windows 无命令行启动与 EXE

两种入口使用同一套 WEB 页面和控制功能，自动打开浏览器，并显示小型管理窗口。Windows 上关闭管理窗口会收进系统托盘，PC 工具继续运行。双击托盘恢复管理窗口，右键菜单提供“打开控制页面”“显示管理窗口”和“停止并退出”。只有“停止并退出”才停止 PC 工具，不停止受控设备上的音乐或服务。没有开机自启或系统服务安装。

托盘图标为深色圆底、绿色播放符号，表示本机 WEB 工具运行中，不表示受控设备在线或正在播放。Windows 可能将新图标放到任务栏的“显示隐藏的图标”区域。若托盘不可用，窗口会保留可见并提示，不会隐藏到无法恢复的状态。

| 入口 | 运行环境 | 适合情况 |
| --- | --- | --- |
| 根目录 `启动WEB工具（无命令行）.vbs` | 本机 Python、Tk 和 cryptography；通过 pythonw 启动 | 经常修改源码，直接使用当前网页与后台 |
| `outputs/PC-WEB-EXE/LivingRoomWeb/LivingRoomWeb.exe` | 自带 Python 和依赖，无需另装 | 日常独立使用，整个文件夹一起移动 |

EXE 采用目录版，不在每次启动时向系统临时目录解压。不要仅复制 EXE，需保留旁边的 `_internal` 文件夹。没有控制台窗口；网络发现和档案权限处理的辅助进程也隐藏命令行。

在本项目内启动时，两种版本共用 `local/web-toolkit/devices.local.json`，不改变或导出已有授权。EXE 移到独立目录后，使用 EXE 旁的 `用户数据` 文件夹，需要在那里重新配对。公开分发时不要附带这些用户数据。

同一端口重复启动桌面工具会打开已有服务，不重复创建后台。比较另一版本前，先在原管理窗口点“停止并退出”。旧 CMD 版或其他程序占用 8760 时会提示冲突，不擅自结束其他进程。

若源码版找不到 Python，可设置环境变量 `LIVING_PLAYER_PYTHONW` 为希望使用的 `pythonw.exe` 完整路径；缺少依赖按上文安装。原 CMD 保留为排查启动错误的入口。

从源码构建 EXE：

```powershell
python -m pip install -r tools/web-desktop-build-requirements.txt
./tools/build-web-desktop.ps1
```

构建过程只打包显式指定的程序与网页，不带入配对文件、日志或 APK 签名密钥。产物、构建缓存和临时目录分别位于忽略的 `outputs/`、`local/web-desktop-build/`。

## 连接与操作

先在受控端临时允许配对，在网页搜索、核对六位码并批准。受控端为 PC 签发独立授权。已有 LP1 长码仅用于备用迁移导入，不是六位配对码，包含控制权限，不应公开。

管理窗口可保存、命名、切换、忘记设备及更新地址。切换清除旧画面和读数、取消待处理请求，不停止音乐。未选中设备不轮询。

桌面横向排列操作、信息和画面；窄竖屏将画面放在上方。画面等比显示，音乐三键为上一首、播放／暂停、下一首。右上角设置可选音乐按钮模式及打开使用说明。

画面默认手动刷新，可开启每三秒刷新。鼠标滚轮转成画面中的滑动，Shift＋滚轮横向滑动，Ctrl／Meta＋滚轮保留浏览器缩放。关闭画面停止截图传输，前台媒体状态继续同步。

## 状态与数据

绿色表示参考正常、黄色提示留意、红色表示高温或异常、灰色为中性或失效。阈值只是页面提示，不修改充电保护。手机显示电池和供电；盒子显示外接电源和芯片温度。

设备档案保存在 local/web-toolkit/devices.local.json，目录限制为本机用户；浏览器不持有控制令牌或私钥。工具仅监听 127.0.0.1，与设备之间固定 TLS 证书。请勿将它改为局域网监听或公网入口。

断开本页停止当前页请求，不停止音乐或受控服务，也不撤销授权。彻底停用某个控制端，应在受控端撤销相应授权。
