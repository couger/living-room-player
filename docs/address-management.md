# 地址变化与重连

修改控制端保存的地址不会改变受控端网络配置或原配对授权。

## Android 控制端

在“我的播放器 → 管理”选择“修改 IP 地址”，输入不含网址和端口的设备地址，验证后保存；也可选择“自动查找新地址”。正在控制时可从“设置 → 切换／管理设备”返回设备列表。验证失败保留原档案。

控制页在连接中断时可尝试重新发现；成功后校验设备证书及原授权，再保存地址和恢复连接。没有授权的其他设备不能冒充原设备。

## WEB 工具

在“管理／添加设备”中选择“修改 IP 地址”或“自动查找地址”。工具只更新指定档案，不自动切换到其他设备，也不停止音乐。

自动查找依赖受控端允许发现及网络支持广播；关闭发现时仍可手动输入地址。授权被撤销后，修改地址不能恢复权限，需要重新配对。路由器可为常用播放器保留 DHCP 地址。
