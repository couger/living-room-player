# 本机配置与控制职责

| 受控端本机管理 | 控制端及 WEB |
| --- | --- |
| 充电保护、电量／温度阈值、系统无操作熄屏时间 | 查看策略、供电和状态 |
| 音乐 APP、实体按键识别及绑定 | 查看结果，按既有配置操作音乐 |
| 受控服务、安全开关、配对批准与撤销 | 管理自身连接，操作屏幕、媒体、唤醒和 HDMI |

手机提供充电与待机表单、迟滞参数说明和异常提醒。盒子显示外接供电、无电池，以及画面传输、HDMI 显示和整机待机之间的区别，不使用手机电池保护参数。

所有 /config 修改，以及按键工具、亮度修改和整体服务停止，均要求本机管理员凭据与回环连接。普通配对凭据经端口转发进入回环地址，也不会变为本机管理员。

完整屏幕控制仍可能进入设备设置，本机专用接口不等于物理本人认证。系统按家庭使用场景采用固定分工，不新增额外分级授权。

暂停充电不证明旁路供电；电流、温度和电量为驱动读数，不生成电池健康评分。长期音乐使用需自行验证后台策略、供电和温控表现。
