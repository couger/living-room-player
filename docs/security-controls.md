# 配对、安全开关与迁移

在受控端“安全与配对”临时开放三分钟；控制端或 PC 工具搜索设备，核对双方六位数字并在受控端批准。每次配对创建独立授权，可单独撤销。新配对默认关闭，服务重启后配对窗口关闭。

完成从旧共享凭据到独立配对的迁移后，可关闭“兼容旧配对凭据”。旧共享凭据不能按副本单独撤销，关闭兼容会同时停用这些副本。请先确认所有需要的控制端已完成独立配对。

关闭局域网发现不会关闭直接控制连接；已保存地址仍可用，但地址变化后的自动查找依赖发现。普通控制和 PC WEB 不依赖系统 USB／无线调试。

| 操作 | 影响 |
| --- | --- |
| 断开连接 | 停止当前控制页画面与轮询，保留配对；音乐和保护继续 |
| 忘记设备 | 删除该控制端的档案，不撤销服务器授权 |
| 撤销设备授权 | 阻止该独立凭据再次访问，终止对应活动画面；其他独立配对不受影响 |
| 关闭新配对 | 清除待处理请求，已有授权继续使用 |
| 关闭发现 | 不回复搜索，原 TLS 控制入口继续运行 |
| 停止受控服务 | 停止整体远控，并恢复本工具管理的充电设置 |

受控端升级需沿用原签名。覆盖安装后，在本机“启动／恢复服务”更新后台助手；只有控制端更新不能改变旧受控端的权限检查。设备证书、配对和本机配置应保留，签名不同无法覆盖安装。

安全管理、配对批准与配置修改要求本机管理凭据和回环连接。更多见 [配置职责](power-ownership.md)。
