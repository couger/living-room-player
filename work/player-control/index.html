Web 调试工具 · 使用说明

这是家庭局域网调试入口。日常操作优先使用原生控制端 APP；此网页当前使用 HTTP，密码认证不等于传输加密，请勿开放到公网。

  1. 两端连接家庭 Wi-Fi，按浏览器提示输入调试账号密码。
  2. 左侧操作被控端，中间查看被控端状态，右侧点击、长按或拖动画面。
  3. 画面默认手动刷新；勾选后每 3 秒更新。安全锁屏需正常解锁。
  4. 电池电量不足 20% 显示黄色、不足 10% 显示红色。温度达到 38℃ 提醒、达到 42℃ 显示高温；这是页面参考阈值，不代表更改充电保护设置。
  5. “断开本页”停止本页请求并清除当前画面，不停止音乐、电池保护或受控服务，也不撤销已授权 APP 或清除浏览器缓存的密码。真正停用应在受控端停止服务。
  6. 日常可关闭 USB／无线调试。Web 停用、配对权限和发现限制详见工具包安全说明。

状态颜色同时配文字说明。连接中断后，数值变灰并标为上次读数，不代表当前设备状态。
