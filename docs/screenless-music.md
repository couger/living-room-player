# 无屏音乐使用

先在受控端选择音乐 APP，并在该 APP 内准备可播放曲目。以后通过控制端、WEB、快捷入口或绑定实体键播放／暂停，不调用音乐账号私有 API。没有系统媒体会话时会尝试启动所选 APP；不能保证任意音乐 APP 冷启动都能自动选歌。

首次实体键启动需盒子待机或 HDMI 关闭；已有有效媒体任务后，可按同一键暂停、恢复。原按键功能仍保留，真正睡眠时能否收到按键依赖固件。

关闭控制画面只停止网络画面传输，不停止音乐。关闭 HDMI 不等于系统待机，也不等于关闭投影仪；HDMI 音频可能随之中断。USB 输出是否连续、功耗和深度休眠唤醒需要按实际设备验证。

盒子活跃远控期间可显示“远程控制中”提示，本地输入会报告给控制端；提示不阻止本地操作。最后一次远控请求约 25 秒后提示失效。控制端退出前台后停止轮询，不继续维持活跃远控。

音乐按钮模式与 CEC 边界见 [音乐按钮、HDMI 与 CEC](music-button-modes.md)。
