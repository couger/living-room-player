# 实体遥控器识别与绑定

仅在盒子受控端本机操作。控制端与 WEB 只查看绑定结果。

1. 打开“识别与绑定按键 → 识别所有实体按键”。
2. 按一次目标遥控器键，界面列出 Linux KEY_* 名称。
3. 点击名称确认绑定；或关闭识别窗口，再从“绑定已识别的按键”选择，无需重新按键。
4. 如需取消，在同一菜单选择“解除播放键绑定”。

支持有效 KEY_* 按键，包括 KEY_TEXT、KEY_REPLY，不限于 F13–F16。Linux 键名不直接等于 Android 功能；F13 等也可能已有固件用途。绑定不屏蔽原功能，应优先选择不常用按键，避免电源键。

识别最长 60 秒，暂停绑定键的播放触发。后台最多暂存 32 次输入事件，停止后清空；APP 在本次运行内保留最多 32 个去重候选键名，不记录到磁盘。APP 退出后候选清空，已保存的绑定保留。

无音乐任务时，首次实体键启动需盒子待机或 HDMI 关闭；所选音乐 APP 有播放／暂停等有效会话后，可继续用绑定键暂停和恢复。真正睡眠期间能否收到按键取决于硬件及固件的唤醒能力。
