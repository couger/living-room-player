# 音乐按钮与 HDMI／CEC（0.9.3）

控制端设置菜单中的“音乐按钮模式”、WEB 右上角“设置”提供两种方式：

- 普通播放／暂停：控制受控端选定的音乐 APP，不主动关闭 HDMI。暂停不主动唤醒盒子。
- 关闭 HDMI 并播放／暂停：仅支持盒子，必要时唤醒系统，关闭 HDMI，执行播放或暂停，最后复核 HDMI 及媒体状态。不会恢复 HDMI，也不发送投影仪待机命令。失败不自动重发。

选项按设备保存在发起端，不修改受控端的充电、待机、按键或音乐 APP 配置。APP 与浏览器各自保存选择，不互相同步模式设置。APP 小组件及下拉快捷按钮沿用该 APP 为同一设备保存的模式。

## 按钮状态

APP 控制页与 WEB 可见时约每两秒读取轻量媒体状态，播放图标显示所选 APP 的实际系统媒体会话。画面刷新与媒体同步分开；画面关闭仍同步。APP 退出前台、网页隐藏或断开后停止此轮询。小组件及下拉按钮不增加后台轮询。

新版受控端支持明确的播放／暂停意图：点击播放图标发送播放，点击暂停图标发送暂停。若另一端先改变状态，相同意图不会反向切换。请求使用编号与忙碌状态确认，接收请求不等于成功。旧受控端仍使用旧切换协议，需要更新才能提供完整保证。

## 实体遥控器

仅响应受控端本机绑定的键。无音乐任务时仍需待机或 HDMI 关闭才能首次启动；所选音乐 APP 有播放、暂停等有效媒体任务后，绑定键可切换播放／暂停，无需每次先关闭 HDMI。识别、捕获期间不播放，按键原有功能没有被屏蔽。

## CEC 协调

HDMI 输出、Android 睡眠、投影仪电源是不同状态。HDMI-CEC One Touch Play 可以在盒子唤醒时唤醒显示设备；参见 [Android 官方 CEC 说明](https://source.android.com/docs/devices/tv/hdmi-cec)。关闭 HDMI 本身不等于投影仪待机。

音乐操作不发送 CEC 开关机命令、不改全局 CEC 设置，也不在暂停时自动让盒子待机。这样避免打断仍使用投影仪或其他信号源的家人。

若希望音乐唤醒不带起投影仪，应由受控端本机的使用者选择是否关闭固件中的“一键播放／唤醒电视”联动，并核对投影仪的 CEC 及信号自动开机设置。若投影仪关机也会令盒子睡眠，还需评估“电视待机带盒子待机”的联动。优先调整独立联动选项，不能假定只有一个 CEC 总开关。

当前未自动更改这些固件设置。盒子经 HDMI 切换器、音频分离器连接投影仪，最终行为需现场确认。真正待机后的系统唤醒仍可能触发固件 CEC；本版不能承诺投影仪绝不被唤醒，也不能承诺关闭 HDMI 后远控画面一直可见。
