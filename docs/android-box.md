# Android 盒子兼容性

手机与盒子使用同一个播放器 APK。已适配的盒子平台为 HK1 RBOX K8 / RK3528；功能取决于设备固件、ROOT 和输入驱动，不能仅凭处理器型号推断完全兼容。

- 盒子显示外接供电、芯片温度，不使用模拟电池数据或手机充电保护参数。
- 原生控制端与 PC WEB 对盒子使用按需截图；手机原生控制采用 H.264。
- 支持的盒子可以独立关闭 HDMI 显示输出，区别于整机待机及关闭画面传输。
- 实体键在受控端本机识别和绑定，控制端只显示结果。
- 音乐 APP、按键、电池／待机策略与配对授权由受控端本机管理。

## 显示、电源与音频

关闭 HDMI 可能中断 HDMI 音频，不等于关闭投影仪或电视，也不能保证远控截图一直更新。系统待机可能影响网络、USB 和音乐，需要按具体设备验证。

RK3528 固件可能同时登记 HDMI 和模拟电视输出。应用按底层 HDMI-A-1 接口识别目标，不按显示设备数量或界面名称选择；无法确认映射时会拒绝切换。HDMI 未接入时，部分固件的 DRM 状态节点仍显示开启，此时以合成器的显示电源状态判断按钮状态。“HDMI 开启”表示输出已启用，不代表电视或投影仪已开机。

USB 解码器是否可用、独占音量、DSD／DoP、输出采样率和音频透明性取决于解码器、驱动与音乐 APP。USB 能连接或系统显示播放中，不足以证明实际出声或音频品质。
